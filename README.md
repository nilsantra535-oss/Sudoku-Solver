# 🧩 Sudoku Solver & Interactive GUI (Python + Pygame)

A Backtracking-based Sudoku Solver built in Python, complete with an interactive Pygame GUI for visualization and manual gameplay.

## ✨ Features
- **Interactive Gameplay**: Play Sudoku manually with pencil sketching (temp numbers) and place finalized numbers.
- **Visual Backtracking Solver**: Press `SPACE` to watch the solver visually solve the board in real-time.
- **Validation**: Automatically validates whether placed numbers comply with Sudoku rules.
- **Strike System**: Tracks incorrect number placements.
- **Timer**: Displays elapsed time during gameplay.
